LOGO AND SALESPERSON PHOTOS (optional — shows them on every computer)

1. Company logo:   already included (assets/logo.png for the header, assets/logo-icon.png for the sidebar)
2. Team photos:    put photos here as      assets/team/<name>.jpg
   Name = salesperson name in small letters, spaces replaced by "-". Examples:
     Shama          -> assets/team/shama.jpg
     Neelam Goyal   -> assets/team/neelam-goyal.jpg
     Priyanka Arora -> assets/team/priyanka-arora.jpg
     ANJALI         -> assets/team/anjali.jpg

You can also upload the logo and photos from Admin inside the dashboard,
but those are saved only in that one browser. Files in this folder work everywhere.
A photo uploaded in Admin is used first; otherwise the file here; otherwise initials.
